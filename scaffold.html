Bruce-D0WD

Open-source hardware firmware for the ESP32-D0WD with an SSD1306 OLED.

ESP32-D0WD SSD1306 OLED GPL‑3.0

Flash from your browser

Connect your ESP32-D0WD over USB and click below. Flashing uses Web Serial, so you need Google Chrome, Microsoft Edge, or another Chromium-based browser on desktop.

Your browser does not support Web Serial — try Chrome or Edge on desktop. Connecting to the device was not allowed.

Hold the BOOT button while connecting if the device is not detected.

Build from source

  1. Install PlatformIO.
  2. Clone this repository and run pio run.
  3. Flash over USB with pio run -t upload, or generate the browser-installer binary:
esptool.py --chip esp32 merge_bin -o firmware/bruce-d0wd-merged.bin \
  --flash_mode dio --flash_freq 40m --flash_size 4MB \
  0x1000  .pio/build/esp32-d0wd/bootloader.bin \
  0x8000  .pio/build/esp32-d0wd/partitions.bin \
  0xe000  ~/.platformio/packages/framework-arduinoespressif32/tools/partitions/boot_app0.bin \
  0x10000 .pio/build/esp32-d0wd/firmware.bin

Place the resulting bruce-d0wd-merged.bin in a firmware/ folder next to this page so the installer can find it.
